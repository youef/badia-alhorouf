# بادية الحروف 🐪

لعبة تعليمية تفاعلية عربية ثنائية اللاعبين مبنية بصفحة HTML واحدة وThree.js.

## التشغيل

افتح `index.html` مباشرة في المتصفح أو انشر المستودع على Netlify.

## التحكم

- فواز 🔴: W A S D للحركة و E للتفاعل.
- زياد 🔵: الأسهم للحركة و Enter للتفاعل.
- على الجوال: عصا التحكم وزر التفاعل.

## المحتوى الحالي

- تعليم الحروف والكلمات والأرقام.
- البئر وسقي الغنم.
- الخيام والنار والقهوة والعشاء والنوم.
- ديوان الشيخ والحوار والأسئلة.
- سباق الخيل.
- الصيد بالمقلاع والصقر.
- الضب والجرابيع والطيور.
- استقبال الضيوف وتقديم القهوة.
- دورة نهار وليل وأصوات البادية.
